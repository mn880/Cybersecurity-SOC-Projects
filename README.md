# SOC Investigation Lab Portfolio

This repository contains hands-on **Security Operations Center (SOC) investigation projects** focused on alert triage, threat detection, and log analysis across endpoint, network, and SIEM environments.

The investigations simulate real SOC workflows including **EDR alert validation, phishing analysis, brute-force detection, and SIEM-based incident triage.**

---

## Investigation Cases

### EDR Alert Investigation
Analyzed endpoint telemetry and process activity to investigate high-severity alerts and validate suspicious process behavior.

Folder: `edr-alert-investigations`

---

### Phishing Email Investigation
Investigated phishing emails by analyzing headers, malicious URLs, and attachments to identify indicators of compromise.

Folder: `phishing-email-investigation`

---

### SSH Brute Force Detection
Analyzed Linux authentication logs to detect brute-force login attempts and confirm unauthorized root access.

Folder: `ssh-bruteforce-investigation`

---

### SIEM Alert Triage – Initial Access
Investigated authentication anomalies in Splunk and validated brute-force activity resulting in successful compromise.

Folder: `siem-initial-access-triage`

---

### SIEM Alert Triage – Persistence
Analyzed Windows event logs to identify malicious scheduled task creation used to establish persistence.

Folder: `siem-persistence-triage`

---
